## 1.8 시작 팝업 '다음부터 묻지 않기' (2026-07-31 구현 · 실기기 통과)

- ※App.js는 `modeAutoStart`면 **오버레이를 렌더 자체를 안 한다** — effect로만 해소하면 한 프레임 깜빡인다
