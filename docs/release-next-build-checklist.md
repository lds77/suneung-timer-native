  **잠금 시간을 15초 / 30초 / 1분 / 5분으로 나눠 각각 이탈 0회인지 기록할 것.**
  실패가 잦으면 플랜 B는 `com.apple.springboard.lockcomplete` Darwin 통지(즉시·확실하지만
  비공식 통지명 — 심사 거절·OS 업데이트로 깨질 위험 감수). 2026-07-28 사용자 결정: **먼저 실기기로 판단**
- 참고: Forest(iOS)도 "잠그면 나무가 계속 자람"을 제공하지만, **잠금화면 알림으로 다른 앱을 열면
  그대로 통과되는 같은 구멍**이 있다 — 위 'iOS ②' 한계는 이 카테고리의 표준 수준

        하나도 안 뜸**(20초·30초·1분 지점을 지나므로 네이티브 취소가 되는지 여기서 판가름)

## 1.7 ★다음 네이티브 빌드 대기 — 🔥모드 화면 꺼짐을 시스템에 맡김 (2026-07-29 구현, 양 플랫폼)

사용자 요청: 🔥모드가 keep-awake로 화면을 계속 켜 둬서 **배터리 심리적 부담**이 컸다.
"잠금화면 시계를 켜놓고 쓰고 싶어할 사용자는 아주 소수" → **keep-awake를 아예 잡지 않는다.**
무동작 감지·터치 리셋은 전부 OS가 하던 대로 하고, 기기 설정의 화면 시간 초과가 그대로 적용된다.
**1.6(화면 끄기 = 이탈 아님)이 먼저 깔려야 성립**하므로 같은 빌드에 함께 나간다.
**OTA 배포하지 않는다 (2026-07-29 사용자 결정 — 정식 빌드로만).**

- ★**앱이 화면을 직접 끌 수는 없다**★ — 안드는 device admin, iOS는 아예 불가.
  '꺼짐 방지를 안 하는 것'이 전부이므로 **기기가 "화면 계속 켜기"면 안 꺼진다**(문의 시 설명용)
- 설정 항목 없음(항상 동작) — 사용자 결정: "켜기 옵션은 불필요, 자동으로 꺼지면 된다"
- 구현: useAppState `keepScreenAwake()`/`setKeepAwake` + `lastTouchAt`,
  `src/utils/focusAway.js`의 `wasIdleBeforeBackground`(15초, 테스트 3개) +
  App.js **루트 View와 잠금 오버레이**의 `onStartShouldSetResponderCapture`(터치 시각만 기록,
  false 반환이라 터치 처리·슬라이드 해제 PanResponder에 관여하지 않음)
- **안드 구빌드 안전장치**: `screenStateSupported()`가 false면 **예전처럼 keep-awake 유지**.
  안 걸면 vc68 이하에서 화면이 꺼질 때마다 스스로 이탈을 만든다(넛지 알림 + exam 타이머 정지)
- **iOS 판정 근거 = 마지막 터치 시각**: 다른 앱으로 나가려면 반드시 화면을 만져야 하므로
  '15초 넘게 터치 없음 + 백그라운드'는 사람이 나간 게 아니라 화면이 꺼진 것.
  네이티브 잠금 감지(1.6)가 실패하는 **암호 미설정 기기에서도 오탐이 안 나는 것이 이 판정의 목적**
  - 15초로 잡은 근거: **iOS 자동 잠금 최솟값이 30초**라 자동 꺼짐은 항상 마지막 터치 +30초 이후,
    앱 전환은 터치 +1~2초 — 두 경우가 넉넉히 갈린다
  - 부작용: 1.6의 'iOS ②' 한계가 조금 넓어진다 — 방치해서 꺼진 뒤 깨워서 다른 앱을 오래 써도 이탈 0.
    (안드는 `lastOnAt` 기반 10초 규칙이 그대로 적용돼 막힌다)
  - 반대로 **화면을 만지고 나간 정상 이탈은 그대로 잡힌다**(폰을 집어 앱을 전환하면 터치가 남음)
- 문구 변경: 모드 선택 "화면 켜두고 집중 도전!" → **"폰 내려놓고 집중 도전!"**(더 이상 켜지지 않으므로),
  잠금화면 첫 사용 가이드에 "화면이 꺼져도 기록은 계속돼요" 한 줄 추가
- 실기기 검증 항목:
  - [ ] **안드**: 🔥모드 시작 후 방치 → 기기 설정의 화면 시간 초과대로 꺼짐 → 복귀 시 **이탈 0회**,
        넛지 알림 없음 (1.6 검증과 같은 경로)
  - [ ] **안드 exam**: 화면 고정 상태에서도 꺼지고, 켜면 고정된 앱으로 복귀 + 타이머 계속
  - [ ] **iOS(암호 설정 기기)**: 방치 → 자동 잠김 → 이탈 알림 안 뜸 → 복귀 시 이탈 0회
  - [ ] **iOS(암호 미설정 기기)**: 위와 동일하게 이탈 0회여야 함 — **터치 판정의 존재 이유**
  - [ ] **iOS 정상 이탈 회귀**: 화면 만지고 다른 앱으로 전환 → 기존대로 20초 뒤 알림 + 이탈 1회

  - [ ] 슬라이드 잠금 해제가 평소처럼 동작(루트/오버레이 터치 capture가 방해하지 않는지) — **회귀 위험 1순위**
