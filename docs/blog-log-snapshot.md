## 2. 폴더 구조 (2026-08-04 정리)

블로그에 쓰는 자산은 **반드시 루트에 둘 것.** 글(.md)이 이미지를 파일명만으로 참조하므로
하위 폴더로 옮기면 링크가 깨진다.

```
구글열공/
├─ CLAUDE.md          ← 지침서 (앱 저장소가 덮어씀 · 수정 금지)
├─ 발행대장.md         ← 이 파일 (코워크가 소유 · 여기에 적을 것)
├─ 네이버_*.md         ← 발행 원고
├─ cap-* / stat-* / widget_* / ios_*  ← 블로그 자산 63개 (이동 금지)
├─ _원본스샷/    ← 카톡 원본·미가공 스샷 (cap-로 복사해 쓴 뒤 여기 보관)
├─ 스토어자산/   ← 앱 아이콘·스토어 스크린샷
└─ 구버전/       ← 옛 html 원고
```
