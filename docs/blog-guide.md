> ※ **아래 0번 '출시 상태표'에서 '출시됨'인 기능만 글로 쓸 것.** 만들었지만 아직 스토어에
> 안 나간 기능을 소개하면 독자가 설치했을 때 없어서 신뢰를 잃는다. 애매하면 빼고 쓴다.

### ★지금은 'iOS가 앞선' 상태다 — 예전과 정반대★
2026-08-04 기준으로 iOS가 1.0.36에서 **1.0.40으로 네 단계 건너뛰어** 올라갔고, Android는
1.0.38에 머물러 있다(1.0.40 = vc72는 빌드 전). 그래서 **한쪽에만 있는 기능을 그냥 쓰면
이번엔 Android 독자가 앱을 깔고 없는 기능을 찾게 된다.** 위 표에서 'iOS만'인 줄은
Android가 따라올 때까지 글에 넣지 않는다.

**공부 모드 이름도 플랫폼이 갈려 있다** — iOS 1.0.40은 **일반모드 / 집중모드 / 울트라모드**,
Android 1.0.38은 아직 옛 이름(편하게 공부 / 집중 도전 / 울트라집중)이다.
글에서는 **새 이름을 쓰되 "이름은 버전에 따라 다를 수 있다"는 식의 군더더기는 붙이지 말고**,
스크린샷은 어느 쪽 기기에서 찍었는지 확인할 것.

> 상태가 바뀌면 이 표만 고치면 됩니다. 글 작성을 요청할 때 "출시 상태표 기준으로"라고 한마디 붙이면

## 2. 타겟과 포지셔닝 (가장 중요)

- **1순위 타겟: 공시생** (9급·7급 공무원시험 준비생). 검색 노출이 실제로 잘 되는 니치이므로 글 제목과 본문에서 공시생을 수능생보다 앞에 둔다.
- 2순위: 수능생·N수생, 3순위: 자격증·어학·내신 수험생.
- 경쟁 구도: "공부타이머" 같은 큰 키워드는 스토어 검색에선 대형 앱이 장악 → **블로그 글 제목으로 그 키워드를 잡아 스토어로 넘기는 게 우리의 검증된 경로**. 열공메이트는 공시/공시생 니치 + 집중밀도 점수라는 차별점으로 승부한다.
- 핵심 차별점 3가지 (글마다 최소 1개는 녹일 것):
  1. **집중밀도 점수** — 시간만 재는 게 아니라 몰입의 질을 점수화 (다른 타이머 앱에 없는 기능)
  2. **딴짓 차단 잠금** — 화면 고정(안드), 앱 차단(iOS), 이탈 알림
  3. **타이머 + 플래너 일체형** — 계획 대비 실행량이 자동으로 연결됨

## 3. 기능 총정리 (이 목록에 있는 것만 사실로 쓸 것)

### 공부타이머 (5가지 모드)
- **카운트다운**: 정한 시간을 거꾸로 세는 기본 모드
- **자유(스톱워치)**: 시간 제한 없이 카운트업
- **포모도로**: 집중-휴식 반복 (기본 25분 집중 + 5분 휴식, 4세트마다 긴 휴식 15분, 시간 조절 가능)
- **랩 스탑워치**: 문제 풀이 랩타임 기록용
- **연속 모드**: 여러 과목·항목을 등록하면 자동으로 이어달리기 (사이 휴식 포함). 실제 시험 시간표를 그대로 넣어 실전 연습 가능. 학년별 과학적 공부법 프리셋 제공:
  - 초등 저학년: 두뇌 워밍업 / 미션 스프린트 / 소리+묵독
  - 초등 고학년: 위와 동일, 집중 시간 증가
  - 중학생: 인터리빙 학습 / 40-10 법칙 / 시험 루프
  - 고등학생·수험생: 52-17 법칙 / 울트라디안 90 / 하드 스타트
- 백그라운드·잠금화면에서도 벽시계 기준으로 정확하게 측정됨 (앱을 꺼도 시간이 어긋나지 않음)
- 과목별 공부 시간 자동 기록·누적

  - ★**이탈 판정 시간을 숫자로 쓰지 말 것**★ — 플랫폼마다 다르다(안드 15초 / iOS 30초).
    앱 문구에서도 같은 이유로 숫자를 뺐다. "잠깐만 벗어나도" 정도로 쓸 것
  - **화면을 끄거나 기기를 잠그는 것은 이탈이 아니다** — 폰을 엎어두고 종이 문제집을 푸는
    사용을 벌주지 않기 위한 설계. **전화가 오거나 통화 중인 것도 이탈이 아니다**
    (★현재 iOS 1.0.40에만 적용. Android는 vc72부터 — 그때까지 글에 쓰지 말 것★)
- **화면 고정** (Android 전용): 울트라모드에서 OS 화면 고정으로 홈 버튼·앱 전환 자체를 차단
- **앱 차단** (iOS 전용): 스크린 타임 연동으로, 미리 고른 방해 앱(유튜브·게임 등)을
  집중모드·울트라모드 동안 열 수 없게 차단 (홈 화면에서 모래시계로 잠김). 세션이 끝나면 즉시 해제
- **울트라모드 전체 차단** (iOS 전용): 켜두면 허용 목록에 넣은 앱(전화·메시지 등)만 남기고 모든 앱이 잠김

### 집중밀도 — 공부를 점수로
- 일시정지 횟수, 이탈 횟수, 완료율, 자가평가 등을 반영해 세션마다 집중도를 점수화
- 등급: **SS(전설) > S+ > S > A > B > C** — 최고 SS, 최저 C (낙제 등급 없음, 동기부여 설계)
- "순공 시간"이 아니라 "순공의 질"을 보여준다는 컨셉으로 소구

### 해야 할 일 (1.0.34 개편)
- 집중탭에서 할 일을 목록별로 관리: 오늘 / 시험(D-Day별 체크리스트) / 직접 만드는 나만의 목록 (예: "기말", "단어장")
- 과목·날짜·반복(매일/주중/주말/직접선택)·우선순위·메모 지정 가능
- 날짜를 미래로 정하면 "예정"에 있다가 그날 자동으로 올라옴, 드래그로 순서 변경
- **집중 시작**: 할 일에서 버튼 한 번으로 그 할 일 타이머 시작 → 공부를 마치면 완료 체크까지 이어지고 공부한 시간이 할 일에 누적 표시
- 오늘 못 한 할 일은 "내일로" 미루기 가능

### 오답노트 (양 플랫폼 출시됨)
- **과목 → 챕터(단원)별로 정리**되는 오답 전용 노트. 과목 탭에서 진입
- 문제/풀이를 적고 **5가지 색 라벨**로 중요도·유형 구분, 챕터 접기로 목록 정리
- **사진 첨부**: 촬영하거나 앨범에서 골라 최대 5장까지. 문제집을 옮겨 적지 않고 찍어서 붙이면 됨.
  사진은 **기기 안 앱 폴더에만 저장**되고 외부로 전송되지 않음 (설정 > 오답노트 저장공간에서 용량 확인·정리)
- **복습 루프**: "복습 순" 정렬이 아직 안 본 것 → 오래전에 본 것 순으로 올려줌.
  "복습 필요한 것만 보기"로 걸러 보고, 다 익힌 문제는 **마스터 완료**로 표시해 목록에서 내림
- 여러 개를 한 번에 선택해 정리/삭제 가능
- ※"AI가 오답을 분석한다" 식으로 쓰지 말 것 — 정리·복습 도구이지 자동 채점/분석 기능이 아님

### 스터디룸 (같이 공부, 양 플랫폼 출시됨)
- **방 코드로 모이는 실시간 공부방** (최대 30명). 통계 탭에서 진입
- **가입 절차 없음**: 닉네임과 캐릭터만 정하면 익명으로 시작 (이메일·전화번호 수집 안 함)
- **좌석 도면**: 스터디카페 / 독서실(칸막이) / 교실(칠판) 3가지 분위기 중 선택해 방을 만들고,
  빈 책상을 눌러 자리를 옮길 수 있음
- 같은 방 사람들의 **지금 공부 중인지 + 오늘 누적 공부시간**이 실시간으로 보임.
  공부 강도(일반/집중/울트라집중)가 자리 색으로 구분됨
- **공개 라운지**: 코드가 없어도 전국 사용자와 같은 방에서 공부 가능
- **공유 범위가 좁다는 점을 강조할 것**: 닉네임·캐릭터·공부 중 여부·오늘 공부시간만 공유되고,
  통계·플래너·과목별 기록 등 상세 데이터는 **절대 공유되지 않음**. 기능을 끄면 서버 정보도 삭제됨
- **다같이 집중**(2026-08 출시): 방에 있는 모두가 같은 시간을 함께 카운트다운.
  누구든 시간을 정해 시작할 수 있다(방장 개념 없음).
  ★**우리끼리 방(코드 방) 전용 — 공개 라운지에는 없다**★. 모르는 사람이 모인 곳에서는
  초대가 아니라 통보가 되기 때문에 일부러 뺐다
- **익명 응원**(2026-08 출시): 열심히 하는 자리에 엄지척을 보낸다. **보낸 사람은 표시되지 않는다** —
  아는 사이끼리만 주고받게 되면 의미가 없어지기 때문. 공개 라운지에서도 된다
- **안전장치**: 불편한 사람은 숨기기·신고로 내 화면에서 지울 수 있고, 라운지 닉네임은 필터를 거친다

### 공부플래너
- **주간 시간표 그리드**: 요일×시간에 과목·계획 블록 배치, 계획 대비 실제 공부량과 달성률 자동 비교
- **매주 반복 계획 vs 이번 주만 계획** 구분 가능
- 계획 미루기(다른 날로 이동), 고정 일정 휴무 처리
- **시험 D-Day 관리**: 시험별 준비 할 일 목록 + 진행률
- 일간/월간 뷰 지원

## 4. 사실 오류 방지 — 절대 쓰면 안 되는 표현

- "365일 잔디", "1년 기록" (X) → 잔디는 4개월(16주)
- "앱 차단" 기능을 Android에 있다고 쓰기 (X) → iOS 전용
- "화면 고정" 기능을 iOS에 있다고 쓰기 (X) → Android 전용
- 오늘 할 일 위젯에서 "iOS도 바로 체크된다" (X) → 위젯 체크는 Android 전용, iOS는 보기 전용
- 잠금 강도를 "시험 모드"·"집중 도전"·"울트라집중"이라고 쓰기 (X) →
  현재 명칭은 **공부 모드: 일반모드 / 집중모드 / 울트라모드** (2026-07-31 변경)
- 이탈 알림을 **"즉시"** 라고 쓰기 (X) → 첫 알림은 몇 초 뒤 예약
- 이탈 판정을 **"10초"** 등 숫자로 쓰기 (X) → 플랫폼마다 다름(안드 15초/iOS 30초), 숫자 없이 쓸 것
- **"화면을 꺼도 이탈이 아니다"·"전화는 이탈이 아니다"를 Android에도 있다고 쓰기** (X, 2026-08 현재) →
  iOS 1.0.40 전용. Android는 vc72부터
- "광고 제거", "프리미엄 결제" 등 수익화 관련 언급 (X) → 무료 앱, 인앱결제 없음
- "AI가 공부를 분석" (X) → 집중밀도는 점수 공식이지 AI가 아님
- 사용자 수·랭킹·수상 등 검증 안 된 실적 지어내기 (X)
- **"재설치해도 데이터가 유지된다"** (X) → 조건부라 단정 불가. "설정에서 파일로 백업" 안내로 대체
- 스터디룸에서 "채팅", "친구 추가/팔로우", "랭킹 경쟁" (X) → 그런 기능 없음(방 코드 기반 + 오늘 기록만)
- 스터디룸 "오늘 이 방 순위" (X) → 순위·랭킹 기능은 없다.
  ※다같이 집중·익명 응원은 **2026-08 출시돼 이제 써도 된다**(단 다같이 집중은 우리끼리 방 전용)
- 오답노트 **음성 메모**, 백업 파일에 **사진까지 담김** (X, 2026-08 현재) → iOS 전용. Android는 vc72부터
- 오답노트를 "AI 분석/자동 채점"으로 (X) → 직접 적고 복습하는 도구
- 오답노트 사진을 "클라우드에 저장/동기화" (X) → 기기 안에만 저장
- 이 문서에 없는 기능 언급 금지. 애매하면 기능 언급을 빼고 쓸 것

## 5. 네이버 블로그 작성 규칙

### 키워드 전략
- **핵심 키워드(띄어쓰기 없이 통째로 사용)**: 공시타이머, 공시플래너, 공시생플래너, 공시생타이머
- 보조 키워드: 공시생 앱, 순공시간, 순공타이머, 공무원시험 공부법, 9급 공부 계획, 포모도로, D-day 위젯, 공부 잔디
- 수능 계열(수능타이머, 수능플래너)은 보조로. 공시 계열이 항상 우선
- "공부타이머", "공부플래너" 같은 큰 키워드는 스토어에선 못 잡지만 **블로그 제목으로는 적극 공략** (예: "공부타이머 앱 추천", "순공시간 재는 법")
- 제목에 핵심 키워드 1개를 자연스럽게 포함. 예:
  - "공시생타이머 뭐 쓰지? 순공시간 말고 집중밀도까지 재봤다"
  - "공시생플래너 앱으로 일주일 계획 짜는 법 (무료)"
  - "공시 공부하다 폰 잡는 습관, 앱 차단 타이머로 끊은 후기"

### 톤과 구조
- **친절한 가이드 어투**: 열공메이트를 잘 아는 사람이 독자의 손을 잡고 하나씩 안내해주는 느낌. "~해보세요", "~하면 돼요" 같은 부드러운 존댓말. 설명서처럼 딱딱하게 쓰지 말 것
- 실사용 경험 톤 (스펙 나열 금지). 문제 상황 → 해결 과정 → 결과 흐름
- 한 글에 기능 1~2개만 깊게. 전체 기능 나열은 하지 않는다 (글감을 아껴서 시리즈로)
- 분량: 1,500~2,500자 + 스크린샷 위치 표시 (예: `[스크린샷: 집중밀도 결과 화면]`)
- 글 마지막에 다운로드 링크 2개(Play/App Store, **1번의 추적 링크 사용**), 웹사이트 링크는 본문 중간에 자연스럽게
- 과장 광고 느낌 금지: "인생이 바뀝니다" (X) → "일시정지 횟수가 줄었다" (O, 구체적 변화)

### 글감 시리즈 예시
1. 공시생 순공시간, 재는 것만으로는 부족한 이유 (집중밀도 소개)
2. 폰 중독 공시생의 딴짓 차단 3단계 (집중 도전 → 이탈 알림 → 앱 차단/화면 고정)
3. 공시생플래너로 주간 계획 짜고 달성률 확인하는 법
4. 홈 화면 위젯 5종으로 D-day와 오늘 계획·할 일 관리하기
5. 공부 잔디 4개월 채운 과정 (통계·리포트 활용기)
6. 수능 시험장 벽시계를 앱에 넣은 이유 (아날로그 시계 모드)
7. 할 일 적어놓고 안 하는 사람을 위한 "집중 시작" 버튼 (할 일-타이머 연동)
8. 울트라집중 설정하는 법 — 폰을 공부폰으로 만들기 (설정 과정 캡처 활용, 잠금 스크린샷 보유)

**신규 글감 (1.0.36~ 기능. 0번 표에서 '출시됨' 확인 후 발행)**

9. **오답노트, 사진 찍어서 5초 만에 만드는 법** — 옮겨 적기 싫어서 안 하던 사람 대상.
   키워드: `오답노트앱`, `오답노트 만드는 법`. 검색 의도가 뚜렷한데 경쟁은 '공부타이머'보다 약한 니치
10. **틀린 문제를 다시 안 틀리게 하는 복습 순서** — 복습 순 정렬·복습 필요만 보기·마스터 완료 활용기
11. **혼자 공부가 안 될 때, 스터디룸에서 같이** — 방 만들고 코드 공유하는 법.
    키워드: `공시생 스터디`, `같이 공부하는 앱`. **공유되는 정보가 적다는 점(익명·오늘 기록만)을 꼭 함께**
12. **독서실 가기 싫은 날 여는 공개 라운지** — 코드 없이 바로 들어가는 경험담
13. 오답노트 + 플래너 연결해서 취약 과목 잡기 (기존 기능과 신규 기능을 엮는 글)
